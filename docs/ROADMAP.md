# Roadmap

Este roadmap separa a recuperação do núcleo funcional da visão experimental histórica do Project 2.0.

## Concluído

- [x] Monorepo frontend/backend identificado.
- [x] Preview com launcher raiz integrado.
- [x] Centro Operacional com dados reais.
- [x] Criação e conclusão de tarefas.
- [x] Registro de decisões.
- [x] Filtros e histórico derivado.
- [x] Auditoria visual expansível.

## Próxima etapa: estabilização

- [ ] Dividir o painel em componentes de domínio menores.
- [ ] Criar contratos compartilhados TypeScript/Zod.
- [ ] Padronizar erros, loading e notificações.
- [ ] Adicionar testes para resumo, tarefas e decisões.
- [ ] Remover dependências legadas não utilizadas sem apagar módulos conceituais.

## Segurança e produção

- [ ] Adicionar autenticação e escopo por usuário/workspace.
- [ ] Aplicar autorização em todas as mutações e consultas.
- [ ] Criar auditoria persistente e imutável.
- [ ] Definir deploy produtivo do Fastify e configuração de ambiente.
- [ ] Adicionar observabilidade, limites de requisição e backups.

## Expansão do produto

- [ ] Integrar conhecimento e documentos ao Centro Operacional.
- [ ] Evoluir o chat do Xerebro para ações assistidas com confirmação.
- [ ] Criar visões executiva, governança e foco em tarefas.
- [ ] Documentar contratos públicos e políticas de contribuição.

## Fases históricas e experimentais

As fases 179, 185, 195, 200, 202, 204, 206 e 208, além dos módulos de consciousness, symbiosis, neural, XR e dimensional, permanecem como legado de produto e laboratório experimental. Elas podem orientar futuras implementações, mas não devem ser tratadas como capacidades comprovadas até possuírem código integrado, testes, persistência e documentação operacional.
